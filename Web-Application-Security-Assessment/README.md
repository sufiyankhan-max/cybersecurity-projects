# Web Application Security Assessment

## Overview
This project documents a hands-on web application security assessment performed in a controlled lab environment.  
The goal is to identify common web vulnerabilities using standard penetration testing techniques.

## Objectives
- Understand the web application attack surface
- Identify security weaknesses through manual testing
- Map findings to OWASP Top 10 categories
- Recommend mitigation strategies

## Tools Used
- Nmap
- Burp Suite
- Firefox
- OWASP Top 10

## Assessment Summary
- Focused on web service discovery, input validation, and common web vulnerabilities

## Disclaimer
Educational purpose only. No unauthorized testing performed.
