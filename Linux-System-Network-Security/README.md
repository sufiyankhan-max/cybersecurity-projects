# Linux System & Network Security Assessment

## 📌 Objective
The objective of this project is to perform a basic security assessment of a Linux system by identifying open network services, system misconfigurations, and simple privilege escalation vectors.

## 🧪 Lab Environment
- Target Machine: Metasploitable2 / VulnHub (Easy Linux)
- Attacker Machine: Kali Linux
- Network Type: Host-only / Internal Network

## 🛠 Tools Used
- Nmap
- Netcat
- LinPEAS
- Searchsploit
- Linux enumeration commands

## 🔍 Assessment Methodology
1. Network scanning and service detection
2. Service enumeration
3. System enumeration
4. Privilege escalation analysis
5. Risk assessment and mitigation

## 📊 Key Findings
- Multiple open and outdated services
- Weak service configurations
- Misconfigured file permissions
- Basic privilege escalation paths

## 📄 Outcome
This project improved my understanding of Linux system security, network exposure, and basic defensive mitigation techniques.

## ⚠️ Disclaimer
This project was conducted in a controlled lab environment for educational purposes only.
